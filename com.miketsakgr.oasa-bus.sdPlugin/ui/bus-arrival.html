Line Filters: Comma-separated list of bus lines (e.g. "856, 815") to prioritize on the display.

Line Overrides: Customize the color and text of a line's pill. Format: LineID,Color,CustomText (e.g., 856,#e34234,🚌). Add one per line.

Controls & Tutorial

  • Short Press: Scrolls to the next page of buses (if more than 2 are arriving).
  • Double Tap: Cycles to the next configured secondary stop.
  • Long Press (Hold): Forces an immediate API refresh.
  • Dummy Content: Use this toggle for testing and debugging colors without waiting for the API.
